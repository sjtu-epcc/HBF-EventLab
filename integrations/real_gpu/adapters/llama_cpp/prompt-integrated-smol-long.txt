This chapter explains computer memory for students. A program contains instructions and data. When the program runs, the processor repeatedly reads instructions, loads values, performs calculations, and stores results. Main memory has a large capacity, but accessing it takes time. Small caches near the processor keep recently used values. Registers are even smaller and hold the values needed for the current calculation. Storage devices preserve files after power is removed, while ordinary working memory loses its contents. A useful example is editing a document: the file is read from storage, its contents are kept in memory, and changes are eventually written back to storage. These different components cooperate so that a computer can run many tasks efficiently. The next section gives a detailed explanation of this process, step by step, with concrete examples.
