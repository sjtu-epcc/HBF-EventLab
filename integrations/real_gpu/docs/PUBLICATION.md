# Public source snapshot

This repository includes the project sources, build scripts, tests, architecture
figures, experiment designs, validation summaries and complete pinned source
dependencies with their original licenses and provenance records.

Excluded inputs and generated data:

- Root build directories and compiled binaries.
- Model weights, local model profiles and machine configuration.
- Python environments, caches, temporary files and large experiment outputs.
- Local Git credentials and environment files.

Vocabulary-only GGUF fixtures bundled with llama.cpp are retained as upstream
source/test assets; they are not inference model weights.

The release manifest describes this source snapshot. Historical validation
records retain their original scope. Later environment-adaptation and incremental
integration checks are documented separately; they do not imply a new full-model
performance experiment.

Third-party notices and licenses remain in their source directories. No new
license is assigned to project-authored files by this publication.
